使用说明

    

      热启动 · onLink 回调
      
App 保持后台运行 → 本页点击「打开 App」或扫码 → App 收到 onLink，path 与 linkParams 应与本页解析预览一致。

    

    

      冷启动 · getLaunchParams
      
App 未运行 → 链接拉起 → 冷启动 Want 可能先于 Dart handler 到达，插件内部会排队并在 handlerReady 后冲刷，随后 getLaunchParams 快照包含完整 path / uri / linkParams。

    

    

      安装参数 · onInstall（deferred link）
      
OHOS 侧走 AppLinkingKit deferredLink.popDeferredLink()，需要应用市场配置延期获取链接（deferred link），本页无法直接模拟该流程；可先用本页验证 onLink / getLaunchParams 链路，再在真机上验证 onInstall。

    

    

      App Linking（https 链接）注意事项
      
    
        
  • https 形态链接需在 AGC 完成域名校验（domainVerify），未校验时浏览器无法直达 App。
    • 
        
  • 桌面上点「打开 App」若未安装应用通常无反应，属正常现象；请以真机/模拟器扫码为准。
    • 
      

    

    

      分享配置（链接预填）
      
落地页链接自带 ?scheme=&host=&path=&k=v 参数，他人打开即恢复当前配置；追加 auto=1 会在 3 秒倒计时后自动跳转 App。
